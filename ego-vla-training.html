用 Ego 数据训练 VLA：数据格式与训练流程

2026-09-05

人体第一人称视频本身只有像素。要训练 VLA，必须先变成图像、语言和动作标签。下面介绍三个有开源训练代码的项目：用什么 ego 数据、送进训练的张量长什么样、loss 怎么算。

三条路线都是「人体 ego RGB + 语言 → 预测动作」。差别只在动作怎么定义，以及人到机器人怎么接。

1. 人手如何变成夹爪轨迹

Ego 视频里没有电机指令。进入 VLA 之前，要把手的运动写成机械臂能监督的位姿序列：腕部当作末端执行器，手指压成夹爪开合或灵巧手关节。

1.1 共同步骤

  • 得到手：从第一人称视频估计 3D 手，或直接用 VR / ARKit 骨骼。常见表示是腕部位姿 \(T_{\mathrm{wrist}}\in\mathrm{SE}(3)\)，加上 MANO 参数或指尖 3D。
  • 选定坐标系：把未来腕位变到某一固定参考系。EgoVLA 用当前相机系；H-RDT 用 EgoDex 的 ARKit origin（地面静止系）；EgoHumanoid 对齐到机器人头相机后再写相对 \(\Delta\mathrm{EEF}\)。
  • 腕 → 夹爪 / 臂末端：腕位置当平移，旋转常写成 rot6D（旋转矩阵前两列）。这就是夹爪或 EEF 的轨迹 \(p_t, R_t\)。相对动作则取 \(\Delta p_t = p_{t}-p_{t-1}\)。
  • 手指 → 开合或关节：平行夹爪只用一个开合量（拇指到掌的距离，或开/关二值）。灵巧手把指尖或 MANO 再经 IK / 小网络映射到机器人手关节。训练时可以先在人手动作空间里学，部署时再 retarget。

时间上会抽成固定长度的 action chunk（例如 1 秒、16 步），和图像、语言对齐后才送进网络。

1.2 三个项目怎么接

  • EgoVLA：相机系腕 3D + rot6D + MANO。部署时 MANO 走 IK 得到臂 EEF，指尖再映射到机器人手关节。
  • H-RDT：双手各 24 维（腕 3 + rot6D + 五指尖 \(\times 3\)），预训练就在这 48 维上。微调时丢掉人手头，换成机器人 action 维。
  • EgoHumanoid：上肢写成双臂 \(\Delta\mathrm{EEF}\)，手只保留开合，不再保留逐指自由度。

2. EgoVLA

NVILA / Qwen2-VL 做 backbone。图像和语言走 VLM，动作由 trajectory decoder 回归。这是三条里最接近标准 VLM-VLA 的做法。

Yang et al. EgoVLA. arXiv:2507.12440 · GitHub

图 2. EgoVLA 总览：人体第一人称视频经统一动作空间训练、部署。

2.1 数据格式

预处理把 TACO、HOT3D、HOI4D、HoloAssist 写成 HuggingFace 样本。未来腕位用当前相机 pose 的逆，变到当前相机系（transform_to_current_frame）。

  • RGB：当前帧 + 历史 5 步，add_his_img_skip=6，ego 相机。
  • 腕 3D：future_*_wrist_3d，当前相机系，每手 3 维。
  • 腕旋转：训练用 rot6d，每手 6 维，合计 12。
  • MANO：--use_mano True，左右合计 30 维。
  • 语言：--use_short_language_label True。
  • 时间：30Hz 采样，预测未来 30 步，约 1 秒 chunk。

预训练 mix 为 hoi4d_30hz_train+hot3d_30hz_train+taco_30hz_train+holoassist_train_30hz_sub5。动作输出 \(\,48 = 6_{\mathrm{EE}} + 30_{\mathrm{hand}} + 12_{\mathrm{rot6d}}\)。

图 3. HOI4D 第一人称人手轨迹：红为 GT，绿为预测；改语言指令后轨迹变化。

2.2 训练流程

  • 人体预训练：从 vila-qwen2-vl-1.5b-instruct-sft-... 出发；vision tower、mm projector、language model 全解冻。
  • 仿真微调：training_scripts/robot_finetuning/*.sh，lr 降到 2e-5 / 2e-6，仍用同一套 EE / hand / rot loss。
  • 目标：轨迹 decoder 加权 L1/L2。\(\lambda_{\mathrm{LM}}=0\)，关掉 LM next-token。\(\mathcal{L}=20\,\mathcal{L}_{\mathrm{ee}}+5\,\mathcal{L}_{\mathrm{hand}}+5\,\mathcal{L}_{\mathrm{rot}}\)。
  • Batch：HuggingFace Trainer + DeepSpeed ZeRO-3；每卡 16，8 GPU，20 epoch。

2.3 核心代码

3. H-RDT

在 EgoDex 上预训练 DiT / flow，再换 action 头微调到双臂机器人。这是 T5 语言条件的 Diffusion Transformer，不是自回归 VLM。语言是预计算 embedding，训练时不再跑 T5。

Bi et al. H-RDT. arXiv:2507.23523 · GitHub

图 6. H-RDT 总览：ego 人手预训练后再跨本体微调。

3.1 数据格式

源数据是 Apple EgoDex（Vision Pro 头戴 1080p 30Hz + 双手 3D）。H-RDT 自己预计算 48D action 和 T5 语言向量。

  • 配置：action_dim=48，chunk=16，单相机、单帧历史，upsample_rate=3（约 10Hz 抽帧）。
  • 48D：每手 24 维 × 2 = 腕位置 3 + 旋转 6D + 五指尖 3D×5。
  • 坐标系：直接读 EgoDex transforms/*，即 ARKit origin（地面静止系），没有转到当前相机系。
  • 样本：states (1, 48)，actions (chunk, 48) 归一化到 \([-1,1]\)，图像 1080×1920，外加 T5 lang_embeds。
  • 微调：机器人侧常见 action_dim: 14。

这里的 48D 停在 ARKit origin，和 EgoVLA 的「当前相机系腕」不是同一套坐标。

3.2 训练流程

  • 预处理：precompute_48d_actions.py → calc_stat.py（min/max）→ encode_lang_batch.py（T5-XXL）。
  • 预训练：pretrain.sh --mode=pretrain，flow matching \(\mathrm{MSE}(\hat{v},\,a-\varepsilon)\)，其中 \(x_t = t\,a+(1-t)\,\varepsilon\)，\(\mathrm{lr}=10^{-4}\)，最多 100 万 step，语言用预计算 embedding。
  • 微调：加载 backbone，跳过 action_encoder / action_decoder / adaptor / final_layer，按新 action_dim 重初始化。视觉是 SigLIP/DINO，语言是 T5 cross-attn。

图 7. 两阶段训练：人体 ego 预训练，再冻视觉 / 语言、换机器人 action 头。

3.3 核心代码

4. EgoHumanoid

自采集头戴 ego 人体演示，加上少量 Unitree G1 遥操作，共训 \(\pi_{0.5}\)。人侧源数据是头戴 ZED，不是机器人相机。

OpenDriveLab. EgoHumanoid. arXiv:2602.10106 · GitHub

图 8. 野外 ego 人数据与实验室机器人数据对齐后共训。

4.1 数据格式

人体采集：PICO VR + 头戴 ZED Mini。处理链是 reorder → 骨盆轨迹导航 [vx, vy, yaw_rate] → 降采样（默认 ×5）→ 合并双目 JPEG → 手开合 → 转 LeRobot。另有 view alignment，把人体视角往 G1 头相机靠。

  • 图像：observation.images.left，头左相机 RGB。
  • 双臂：action_delta_eef，(H, 12)。
  • 底盘：delta_height (H, 1)，teleop_navigate (H, 3)。
  • 手：hand_status，开合，可按数据集 mask。
  • 语言：prompt，任务描述。
  • 混合：人 / 机多 repo_id，示例权重 [0.66, 0.11, 0.22]。

图 9. 采集硬件：人 / G1 均头戴 ZED Mini，人侧另有 PICO VR。

图 10. 视角对齐：原 ego 图 → 深度 → 重投影 → inpaint。

4.2 训练流程

  • 初始化：加载 pi05_base，Pi0Config(pi05=True)。
  • 目标：flow matching。\(x_t = t\,\varepsilon + (1-t)\,a\)，\(u_t = \varepsilon - a\)，预测 \(v_t\) 对 \(u_t\) 的 MSE。
  • 坏样本：per-sample \(\ell > 10\) 的样本置零，不回传。
  • 规模：示例 50,000 step，batch 256。
